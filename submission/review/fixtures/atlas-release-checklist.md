# Atlas Release Checklist

This is synthetic demonstration content for AgentRAG review. Atlas is a fictional project.

## Before a release

The release operator must verify the backup, run the automated tests, and confirm the rollback procedure before deploying Atlas. If any of these checks fails, stop the release and investigate.

## Responsibilities

The release operator performs the release checks. Access requests are approved separately by the project owner, as described in Atlas Access Guide.
